# Example dataset of behavioural data to complement dataset HCL.

This contains information on stimuli (such as the side the predictive
cue was presented on) as well as response data, including accuracy and
response times

## Usage

``` r
HCL_behavioural
```

## Format

A dataframe of 12 observations and eight variables

- pID:

  participant ID

- trial:

  trial number

- P_cue:

  Are these necessary columns?

- NP_cue:

  Are these necessary columns?

- cue_order:

  whether the predictive cue os presented on the left (1) or the right
  (2)

- correct_out:

  NAre these necessary columns?

- accuracy:

  response accuracy

- RT:

  response time in milliseconds
